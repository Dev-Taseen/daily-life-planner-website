# Daily Life Planner download website

This is a separate Next.js project. In Vercel, import this repository and set the Root Directory to `website`.

When a signed APK is ready, host it at a stable HTTPS URL and set `NEXT_PUBLIC_APK_URL` in Vercel project environment variables, then redeploy. The download link is intentionally hidden until this variable is set.

Before public launch, replace placeholder support details, verify the privacy policy against the actual app behavior, and publish only a signed APK built from the matching source revision.
